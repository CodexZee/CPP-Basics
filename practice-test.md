# Git and GitHub Practice

## Introduction

This is a temporary practice file created to understand the basic Git and GitHub workflow using Visual Studio Code.

Git is a version control system that helps developers track changes in their projects. It allows us to save different versions of our work and return to an earlier version when needed.

GitHub is an online platform where Git repositories can be stored and shared. It is commonly used by developers to manage projects, collaborate with other developers, and showcase their work.

## Git Workflow

A basic Git workflow can be understood as:

**Create → Edit → Save → Stage → Commit → Push**

When a file is created or modified, Git detects the change. We can then stage the change and create a commit describing what was changed.

After committing, the changes are stored in the local Git repository. The `push` operation sends those commits to the remote repository on GitHub.

## Why Git Is Important

Git is an important tool for programmers because software projects are constantly changing. Developers may add new features, fix bugs, improve existing code, or remove unnecessary files.

Without version control, keeping track of these changes can become difficult.

With Git, every important change can be recorded in a commit. This makes it easier to understand the history of a project and work safely.
