# Difference Between Procedure-Oriented Programming and Object-Oriented Programming

## Procedure-Oriented Programming (POP)

* Consists of writing a set of instructions for the computer to follow.
* The main focus is on **functions** rather than data.
* Functions can use **local or global data**.
* Data can move openly from one function to another.

## Object-Oriented Programming (OOP)

* Works on the concept of **classes and objects**.
* A **class** is a template used to create objects.
* Treats **data as a critical element**.
* Decomposes a problem into objects and builds **data and functions around those objects**.

---

# Basic Concepts of Object-Oriented Programming

### 1. Classes

A **class** is a basic template or blueprint used for creating objects.

### 2. Objects

Objects are the **basic runtime entities** in Object-Oriented Programming.

### 3. Data Abstraction & Encapsulation

Encapsulation means **wrapping data and functions together into a single unit**, while abstraction focuses on showing only the necessary details.

### 4. Inheritance

Inheritance allows the **properties and behaviors of one class to be inherited by another class**.

### 5. Polymorphism

Polymorphism means the **ability to take more than one form**.

### 6. Dynamic Binding

Dynamic binding means that the **code to be executed is determined at runtime**.

### 7. Message Passing

Message passing refers to **communication between objects through function or method calls**.

---

# Benefits of Object-Oriented Programming

* Provides better **code reusability** through objects and inheritance.
* **Data hiding** helps in building more secure systems.
* Multiple objects can **co-exist without interfering** with each other.
* Helps manage **software complexity** more effectively.
